🌐 ¿Qué es HTML5?

Es la quinta versión del lenguaje que da estructura a todas las páginas web del mundo.

🦴

No es programación

Es un lenguaje de etiquetas: describe qué hay, no qué hacer.

🏗️

Estructura

Define los muros de la web: títulos, párrafos, imágenes, formularios.

🌍

Estándar mundial

Desde 2014, HTML5 es el estándar oficial de la W3C.

💡 HTML = estructura · CSS = presentación · JavaScript = comportamiento.

🧩 Estructura semántica de un documento

Todo documento HTML5 tiene una estructura clara. Así se organiza:

<!DOCTYPE html> // Indica que es HTML5
<html lang="es">
<head>
<meta charset="UTF-8">
<title>Mi página</title>
<link rel="stylesheet" href="estilos.css">
</head>
<body>
<header> · <nav> · <main>
<section> · <article>
<aside> · <footer>
</body>
</html>

📰 Etiquetas semánticas de HTML5

Son como las secciones de un periódico. Ayudan al navegador, a Google y a los lectores de pantalla.

<header>
Encabezado · logo, título y menú
<nav>
Menú de navegación principal
<main>
Contenido principal de la página
<section>
Sección temática · agrupa contenido
<article>
Artículo independiente · noticia, post
<aside>
Contenido lateral · publicidad, enlaces
<footer>
Pie de página · copyright, contacto

🎯 Antes se usaban <div> para todo. HTML5 trajo significado a la estructura.

📋 ¿Qué es un formulario HTML?

Es la forma en que el usuario ingresa datos: registro, login, compras, comentarios, encuestas…

📝

Registro

Nombre, correo, contraseña → crear cuenta.

🔐

Login

Usuario y clave → iniciar sesión.

🛒

Compra

Dirección, tarjeta → finalizar pedido.

💬

Contacto

Asunto y mensaje → enviar al profesor.

<form action="/enviar" method="POST">
  <input type="text" name="nombre">
  <button type="submit">Enviar</button>
</form>

🔧 Anatomía de un formulario

Cinco etiquetas forman la base de todo formulario web.

<form>
Contenedor · envuelve todo el formulario
<label>
Etiqueta visible · se une con for
<input>
Campo donde el usuario escribe
<textarea>
Campo de texto largo · comentarios
<select>
Lista desplegable · país, edad
<button>
Botón de enviar o resetear
<form>
  <label for="mail">Correo:</label>
  <input type="email" id="mail" name="correo">
  <button type="submit">Enviar</button>
</form>

🔤 Tipos de <input> · Parte 1

Cada type cambia el teclado del móvil y activa validaciones automáticas.

type="text"
Texto corto · nombre, apellido
type="email"
Correo · valida que tenga @ y dominio
type="password"
Contraseña · oculta los caracteres
type="number"
Números · edad, cantidad
type="tel"
Teléfono · teclado numérico en móvil
type="date"
Fecha · muestra calendario

⚠️ Nunca uses type="text" para todo. Usa el tipo correcto: mejora la experiencia y valida solo.

✅ Tipos de <input> · Parte 2

Estos tipos permiten elegir entre opciones o valores especiales.

type="checkbox"
Seleccionar varios · términos, intereses
type="radio"
Elegir solo uno · género, sí/no
type="file"
Subir archivos · imagen, PDF
type="color"
Selector de color · paleta visual
type="range"
Deslizador · volumen, precio
type="submit"
Botón que envía el formulario

💡 Con <select> y <option> haces listas desplegables sin necesidad de inputs.

🛡️ Validación HTML5 (sin JavaScript)

HTML5 valida solo. Estos atributos evitan que el usuario envíe datos malos.

required
El campo es obligatorio
placeholder
Texto de ayuda dentro del campo
minlength / maxlength
Mínimo y máximo de caracteres
min / max
Rango numérico permitido
pattern
Validación con expresión regular
type="email"
Valida formato de correo solo
<input type="email" name="correo" required
       placeholder="tu@email.com">

🎨 ¿Qué es CSS?

Cascading Style Sheets · Hojas de estilo en cascada. Da presentación a HTML.

🦴

HTML

Estructura · esqueleto · contenido

👕

CSS

Presentación · ropa · colores, tamaños, posición

🧠

JS

Comportamiento · músculos · interactividad

✨ Con CSS controlas: colores, tipografía, tamaños, espacios, animaciones, diseño responsive y más.

📎 Formas de aplicar CSS

Hay 3 formas. La externa es la recomendada.

1. En línea
<h1 style="color:red"> · rápido pero desordenado
2. Interno
<style> en el <head> · solo para esa página
3. Externo ✅
<link rel="stylesheet"> · reutilizable en todo el sitio
<!-- En el <head> -->
<link rel="stylesheet" href="estilos.css">

/* En estilos.css */
body { background: #0b0a1f; color: #fff; }
h1   { font-family: 'Fredoka'; color: #ffe66d; }

🎯 Selectores CSS básicos

Los selectores apuntan a elementos HTML para aplicarles estilos.

p { }
Selector de etiqueta · todos los párrafos
.boton { }
Selector de clase · varios elementos
#header { }
Selector de id · único en la página
* { }
Selector universal · todos los elementos
.card p { }
Selector descendiente · p dentro de .card
:hover
Pseudo-clase · al pasar el mouse

⚖️ Cuando hay conflicto, gana el más específico. id > clase > etiqueta.

📦 El modelo de caja (Box Model)

Todo elemento HTML es una caja con cuatro capas. ¡Fundamental para el layout!

content
El contenido · texto o imagen
padding
Espacio interno · entre contenido y borde
border
El borde visible · grosor, color, estilo
margin
Espacio externo · separación con otras cajas
.caja {
  padding: 20px;      /* espacio interno */
  border: 2px solid #4ecdc4;
  margin: 15px;       /* espacio externo */
  box-sizing: border-box;
}
